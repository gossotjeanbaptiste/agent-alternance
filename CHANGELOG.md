# Historique des versions

Une ligne par version publiée (la plus récente en haut) : ce qui a changé pour l'utilisateur.
Les mentions « tour » ne concernent que la version avec la tour (branche `main`).

## 1.4 — rapport, navigateurs, routines planifiées

- **1.4.7** (27/11/2026) — Brouillons dont l'adresse reste à trouver étiquetés « Adresse à trouver » (libellé Gmail,
  catégorie Outlook, retirée une fois l'adresse renseignée) ; l'extension Chrome préremplit aussi les formulaires
  La Bonne Alternance ouverts hors de LMAgent (champs vides seulement, lettre et réponses si l'entreprise est connue).
- **1.4.6** (26/11/2026) — Routines programmées à plusieurs heures par jour, avec un nombre de passages par heure ;
  état des tâches sans accents cassés.
- **1.4.5** (26/11/2026) — Signature Outlook insérée sans casser les accents du mail.
- **1.4.4** (25/11/2026) — Rapport rédigé par le modèle : plus de consignes recopiées dans les titres, chiffres mieux distingués.
- **1.4.3** (25/11/2026) — Rapport de recherche rédigé par le modèle local (page Rapport).
- **1.4.2** (25/11/2026) — Nouveau statut « Demande de disponibilités » (reconnu dans les réponses, sans relance).
- **1.4.1** (25/11/2026) — Formulaire La Bonne Alternance sans Chrome : choix du navigateur (Edge, Brave, Vivaldi,
  Opera, Opera GX préremplis par l'extension ; Firefox : page ouverte, lettre copiée).
- **1.4.0** (25/11/2026) — Page Rapport : bilan des recherches sur une période (impression / PDF, texte à copier).
